# Storm Brigade

Storm Brigade is an original stylized low-poly 3D first-person battlefield prototype for Godot 4 and Android.

## Current map milestone — The Lost Kingdom

The generated world now includes:
- A large rolling battlefield with a broad road network.
- A grand central stone castle with curtain walls, a gatehouse, round towers, battlements, an inner keep, courtyard halls and torches.
- Two hilltop forts, each with perimeter walls, towers, gates and keeps.
- A ruined citadel with collapsed walls, broken columns and rubble.
- Abandoned villages, mud houses, a market square and wells.
- A river, two stone bridges, forests, boulders and defensive cover.
- First-person movement, touch-look, Android virtual joystick, fire and jump controls.

## Technology
- Godot 4.x / GDScript
- Procedural low-poly meshes and built-in materials
- GitHub source control

## Open and test
1. Open the existing Storm Brigade project in Godot 4.
2. Let the editor finish importing the project.
3. Press Run (▶).
4. Start at the southern approach road and walk toward the central castle.
5. On Android, use the left joystick to move, drag the right side to look, and use FIRE / JUMP.

## Important status
This is a large playable greybox/art-direction milestone made from original procedural 3D geometry. It is not yet a finished AAA or photorealistic game. The map needs an actual run on the target Android device for visual, performance and collision testing before the next art pass.
