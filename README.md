# Storm Brigade

A colorful, stylized first-person shooter (FPS) prototype for Android, inspired by the fast, playful feel of classic arcade shooters.

## Current milestone
**Milestone 1 — Offline FPS prototype**
- First-person camera and movement
- Keyboard/mouse controls for desktop testing
- Initial touch-look and tap-to-fire support for Android
- Stylized training arena built from original primitive assets
- Target practice and hit feedback

## Technology
- Godot 4.x
- GDScript
- GitHub for source control

## Project status
Early development. This repository contains the foundation of the first prototype. It is not yet a finished game, Android APK, or online multiplayer release.

## Run
1. Install Godot 4.x on a computer or cloud development environment.
2. Import this folder as a Godot project.
3. Open `project.godot` and press Play.

## Roadmap
1. Offline movement, aiming and target practice.
2. Proper Android virtual joystick, fire and jump controls.
3. Original characters, weapons, maps, sound and effects.
4. Online multiplayer with server-authoritative gameplay.

All game names, characters, maps, art and code will be original.
